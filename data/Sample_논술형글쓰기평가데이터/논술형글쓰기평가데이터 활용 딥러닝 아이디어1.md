# 딥러닝 포트폴리오 프로젝트 아이디어 (투자 시간: 2일)

## 데이터 구조 요약

- 초5(국어·과학·사회·수학)와 20~30대(과학·문화·사회·역사·인문) 대상 논술형/서술형/주제별평가 답안 데이터
- 각 답안마다 8개 분석적 루브릭 점수(과제충실성, 명료성, 구체성, 적절성, 연결성, 통일성, 어휘, 어법) + 총체적 점수 + 전문가 피드백 텍스트 + 형태소 자질(품사 카운트) 라벨링
- 논술형/서술형/주제별평가 각각 원천데이터(csv) 36개 + 라벨링데이터(json) 36개, 총 108쌍 — 샘플 데이터라 규모는 작음 (AI-Hub 원본 데이터셋의 일부로 추정)

## 프로젝트 아이디어 3가지

### 1. 자동 첨삭 채점기 (Automated Essay Scoring)
가장 표준적이고 이력서에 잘 먹히는 프로젝트. KoBERT/KoElectra 같은 사전학습 한국어 모델을 파인튜닝해서 답안 텍스트로부터 8개 분석적 점수 + 총체 점수를 동시에 예측하는 멀티태스크 회귀 모델을 만듦. 데이터가 적으니 사전학습 인코더 freeze 후 헤드만 학습하는 방식으로 과적합을 피하고, QWK(Quadratic Weighted Kappa)로 사람 채점과의 일치도를 평가. 형태소 자질(feature 필드)을 활용한 전통 ML 베이스라인(XGBoost)과 비교하면 "왜 딥러닝이 필요한가"를 보여주는 스토리가 생김.

### 2. 점수 예측 + 근거 하이라이트 (Explainable Scoring)
1번 채점기에 Attention/SHAP 기반 해석을 얹어서, 어떤 문장/표현이 특정 루브릭 항목(예: 통일성, 어법) 점수를 낮췄는지 시각화. 교육 도메인에서 "설명 가능한 AI"는 채용 담당자에게 인상적인 포인트임.

### 3. 루브릭 기반 피드백 생성
답안 + 예측 점수를 조건으로 전문가 피드백과 유사한 문장을 생성(소형 seq2seq 파인튜닝 또는 프롬프트 기반 생성 후 ROUGE/BERTScore로 전문가 피드백과 비교 평가). 생성 품질 평가가 더 까다로워서 난이도는 높지만 차별화는 확실함.
