## 1. Remote Control 관련 확인 사항
- `/remote-control`(또는 `/rc`)로 이 컴퓨터의 로컬 세션을 폰 등 다른 기기와 연결 가능.
- 전제조건: claude.ai 로그인, Pro/Max/Team/Enterprise 플랜 (API 키 방식 불가).
- **로컬 프로세스(터미널)가 살아있어야만 유지됨.** 컴퓨터를 끄거나 터미널을 닫으면 세션이 즉시 종료되고, 폰에서도 사라짐.
- 절전모드/네트워크 순간 끊김 정도는 자동 재연결되지만, 완전 종료·재부팅 시에는 복구 불가 → 재부팅 후 `claude` 재실행 + `/remote-control` 재설정 필요.
- 작업 파일(엑셀 등)은 디스크에 저장되어 있어 컴퓨터를 꺼도 안전함.
- Auto-memory(`~/.claude/projects/<project>/memory/`)는 이 컴퓨터 로컬 디스크에만 존재 — 기기 간 동기화 안 됨. Remote Control로 이 컴퓨터 세션에 접속했을 때만 폰에서도 확인 가능하고, 폰에서 독립적인 새 세션을 열면 접근 불가.

### J~M열: "이동약자" 관련 파생 아이디어 4종 (모두 유지하기로 결정)
| 열 | 아이디어 | 분야 | 2일 실현성 |
|---|---|---|---|
| J | 1순위+7순위 결합 — 장애인콜택시 수요 예측 및 지역 형평성 분석 | Time-Series + 정책분석 | 상 |
| K | 보행로 접근성 시설물 자동 탐지·매핑 (CV) | Computer Vision / 공간AI | 중 |

| M | 이동약자 정책·복지 제도 Q&A RAG 서비스 | NLP / RAG | 상 |

- J열(1+7결합): 1순위 시계열 기법(TFT/PatchTST/N-BEATS + XGBoost/LightGBM 베이스라인 + SHAP)을 장애인콜택시 수요예측에 적용. 데이터는 장애인콜택시 일별 이용현황(서울시설공단/공공데이터포털), 장애인콜시스템정보, 기상자료개방포털(외생변수)로 즉시 확보 가능.
  - 리스크: 콜택시 데이터가 일별 집계 단위라 시계열 변동성이 단조로울 수 있어 딥러닝 우위를 보이는 비교실험 설계가 중요. 장애유형별 세분화 데이터는 비공개라 형평성 분석은 지역 단위(저상버스 보급률 등)로 제한.
- K열(CV 보행 접근성 매핑): AI허브 "보행 안전을 위한 도로 시설물 데이터"(약 102.5만 장, 턱낮춤·점자블록 포함)로 YOLOv8/v11·SAM 기반 접근성 점수화 + Folium/Streamlit 지도.
  - 서사: 보고서에서 지적된 "서울동행맵 등 전용 앱 정보가 부정확하다"는 실제 문제를 기술로 보완.
  - 리스크: AI허브 데이터 승인 대기시간이 2일 일정에 리스크(승인 지연 시 Roboflow/Kaggle sidewalk·curb-ramp 데이터로 대체 검토 필요). 라벨 단위(개별 지점 좌표 여부) 사전 확인 필요.
- L열(고령 보행자 사고위험 예측): 2024년 보행 사망자 920명 중 67%(616명)가 65세 이상, 2025년 고령 보행자 사고 7,301→11,498건 급증. 도로교통공단 연구상 위험도는 교통량보다 노인복지시설·보호구역 등 인프라 격차(PSI 지표, 지역 간 최대 380점 차)에 좌우.
  - 데이터: TAAS(교통사고분석시스템, taas.koroad.or.kr), 보건복지부 노인복지 시설현황(공공데이터포털). PSI 지표 원자료 공개 여부 미확인 → 직접 위험지수 설계 가능성 높음.
  - 모델: 지역 단위 격자/그래프로 사고통계·인프라 밀도를 표현 (TabNet 또는 GNN) vs XGBoost 베이스라인 비교.
  - 리스크: 정형 데이터에 딥러닝을 적용하는 이유를 방어해야 함. TAAS 대량 다운로드가 번거로워 2일 실현성 "하".
- M열(이동약자 정책 RAG): `이동약자_대중교통_국내외비교_보고서.docx` 자체를 코퍼스로 활용. LangChain/LlamaIndex + BGE-m3 + Hybrid Search(FAISS/Qdrant) + 한국어 sLLM + RAGAS. 국가법령정보 API, 복지로 문서 추가 활용.
  - 리스크: 평가용 Q&A 셋 직접 소량 제작 필요(5순위 RAG와 동일 리스크). 2일 실현성 "상".
