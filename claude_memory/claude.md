## 1. Remote Control 관련 확인 사항
- `/remote-control`(또는 `/rc`)로 이 컴퓨터의 로컬 세션을 폰 등 다른 기기와 연결 가능.
- 전제조건: claude.ai 로그인, Pro/Max/Team/Enterprise 플랜 (API 키 방식 불가).
- **로컬 프로세스(터미널)가 살아있어야만 유지됨.** 컴퓨터를 끄거나 터미널을 닫으면 세션이 즉시 종료되고, 폰에서도 사라짐.
- 절전모드/네트워크 순간 끊김 정도는 자동 재연결되지만, 완전 종료·재부팅 시에는 복구 불가 → 재부팅 후 `claude` 재실행 + `/remote-control` 재설정 필요.
- 작업 파일(엑셀 등)은 디스크에 저장되어 있어 컴퓨터를 꺼도 안전함.
- Auto-memory(`~/.claude/projects/<project>/memory/`)는 이 컴퓨터 로컬 디스크에만 존재 — 기기 간 동기화 안 됨. Remote Control로 이 컴퓨터 세션에 접속했을 때만 폰에서도 확인 가능하고, 폰에서 독립적인 새 세션을 열면 접근 불가.
