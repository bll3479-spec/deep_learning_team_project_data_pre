## 8. 세션 마무리 — 데이터셋 링크 정리 및 모듈별 요약

### 8.1 14번 데이터셋 링크 모음 파일 생성
- 사용자가 "데이터셋 링크들 보내봐"라고 요청 → 지금까지 조사한 14번(9+13 결합) 관련 링크를 모듈A/B/C + 결합 단계 전용으로 나눠 정리.
- 처음엔 채팅 텍스트로만 답했으나, 사용자가 다시 요청해서 별도 파일로 만들어 전달함(채팅 텍스트로는 부족하다고 판단한 것으로 보임).
- 신규 파일: `14번_데이터셋_링크.md` (모듈A 6개, 모듈B 4개(원본+대체 3종), 모듈C 5개, 결합용 3개 링크 정리)

### 8.2 모듈별 "수행 작업 vs 산출물" 브리핑
14번(9+13 결합, 이동약자 이동성+보행안전 통합 대시보드)을 4개 모듈로 나눴을 때, 각 모듈이 실제로 해야 할 작업 단계와 최종 산출물은 다음과 같다(`이동약자_통합대시보드_기술설계.md` 4·9절 기준 정리).

**모듈A — 콜택시 수요·형평성 예측 (수요예측팀)**
- 수행 작업: ① 데이터 수집(장애인콜택시 일별 이용현황·기상·요일/공휴일·저상버스 보급률) → ② 시계열 딥러닝(TFT/PatchTST/N-BEATS)으로 수요·대기시간 예측, XGBoost/LightGBM과 성능 비교 → ③ 예측된 대기시간 격차와 저상버스 보급률의 관계를 XGBoost+SHAP으로 분석
- 산출물: RMSE/MAE 비교표(통계모델 vs 딥러닝), 지역별 SHAP summary plot(저상버스 영향력 시각화), 형평성 우선순위 리스트, 자치구별 "대기시간 격차 지수"

**모듈B — 보행 접근성 탐지 (CV팀)**
- 수행 작업: ① 데이터 수집(AI허브 보행로 사진, 승인 지연 시 Roboflow/Kaggle 대체) → ② YOLOv8/v11 또는 SAM으로 턱낮춤·점자블록·경사로 탐지 → ③ 지점별 접근성 점수 산출
- 산출물: 접근성 점수 지도, mAP·추론속도(FPS) 성능 지표, 자치구별 "접근성 점수"

**모듈C — 고령 보행자 사고위험 예측 (정형데이터팀)**
- 수행 작업: ① 데이터 수집(지역별 교통사고 통계·노인복지시설 밀도·인프라 변수) → ② XGBoost/TabNet으로 자체 설계 위험지수 예측 → ③ SHAP으로 위험 요인 해석
- 산출물: 사고위험지수 예측 성능(RMSE/MAE), SHAP summary plot, 자치구별 "사고위험지수"

**결합 (통합·대시보드팀)**
- 수행 작업: ① 3개 모듈 출력을 자치구 코드 기준으로 병합 → ② 종합 우선순위 점수 계산(가중합, 근거 약하면 동일 가중치 1/3씩 기본값 + 민감도 분석) → ③ Streamlit/Folium 3탭 대시보드 구축(이동성/보행안전/종합)
- 산출물: Streamlit/Folium 3탭 대시보드, 자치구별 종합 우선순위 지도, 형평성 개선(모듈A)과 인프라 우선순위(모듈B+C)를 연결한 정책 제언 최종 리포트
